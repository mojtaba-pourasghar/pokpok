# استودیوی صداگذاری پوپو

ابزار محلی برای سه کار (سومی، خبرها، پایین‌تر):

1. **صدای گوینده** (پوپو دختر است؛ فقط صداهای زنانه‌ی آواشو پیشنهاد می‌شود، پیش‌فرض «پونه»): ساخت صدای موقت جمله‌های پوپو با سرویس TTS «آواشو»، تا وقتی گوینده‌ی واقعی
   جمله‌ها را ضبط کند.
2. **صدای حیوان‌ها و وسایل**: جایگزین کردن صداهای سنتزی نسخه‌ی قبلی با صدای واقعی‌ای که خودتان پیدا
   یا ضبط کرده‌اید.

همه‌چیز **مستقیم داخل خود پروژه** نوشته می‌شود و با ساخت بعدی داخل APK می‌رود.
صدا و جلوه **هیچ‌جا آپلود نمی‌شوند** و هیچ چیزی خودکار کامیت یا پوش نمی‌شود؛ تنها چیزی که بیرون می‌رود خبری
است که خودتان «امضا و انتشار» را برایش بزنید.

## اجرا

نیازها:

- **Node.js 18 یا بالاتر**: <https://nodejs.org> (نسخه‌ی LTS)
- **ffmpeg** روی PATH. روی ویندوز در PowerShell بزنید `winget install Gyan.FFmpeg`، بعد PowerShell
  را ببندید و دوباره باز کنید. برای بررسی: `ffmpeg -version`

### ویندوز

روی `tools\voice-studio\start.bat` دوبار کلیک کنید. بار اول بسته‌ها را نصب می‌کند و حدود ۱۵ ثانیه بعد
مرورگر روی <http://127.0.0.1:5174> باز می‌شود. برای بستن، پنجره‌ی سیاه را ببندید.

یا از ترمینال:

```powershell
cd C:\path\to\pokpok\tools\voice-studio
npm install      # فقط بار اول
npm start
```

### لینوکس / مک

```bash
cd tools/voice-studio
npm install
npm start
```

## به کجا وصل است

|---|---|
| متن جمله‌ها | `assets/content/voice_lines.json` (همان فایلی که برنامه می‌خواند؛ ۶۲۲ جمله، هر کدام با شناسه، متن و نام فایل) |
| خروجی صدای گوینده | `assets/audio/voice/<file>.mp3` (مثلاً `c1s1_s1.mp3` برای جمله‌ی `c1s1.s1`) |
| فهرست صداهای ماشینی | `docs/voice/tts_generated.json` |
| فهرست صداها (حیوان‌ها، وسایل، صدای محیط، سازها) | `assets/content/asset_manifest.json` |
| فهرست همه‌ی فایل‌های صدا (برنامه و آزمون‌ها) | `assets/content/asset_manifest.json`: استودیو بعد از هر ساخت، پاک‌کردن یا جایگزینی خودش به‌روزش می‌کند |
| خروجی صدای حیوان‌ها و وسایل | `assets/audio/sfx/<file>.mp3` (همان فایلی که برنامه پخش می‌کند) |
| منبع و مجوز صداهای واقعی | `docs/audio/sfx_sources.json` |
| تلفظ (متن با اعراب) | فیلد `spoken` در `voice_lines.json`، که از `tools/content/spoken_fa.json` می‌آید. همه‌ی جمله‌ها اعراب دارند. فقط استودیو آن را می‌خواند؛ برنامه همان «متن» را نشان می‌دهد. |
| صداهای آزمایشی | `tools/voice-studio/samples/` (بیرون از برنامه و بیرون از گیت) |

## تب «استودیو»: صدای گوینده

1. **توکن** آواشو را در کادر «توکن آواشو» بچسبانید و «ذخیره‌ی تنظیمات» را بزنید. توکن در
   `voice-studio.config.json` همین پوشه ذخیره می‌شود و در گیت نیست.
2. «تست صدا با یک جمله» را بزنید تا پیش از ساخت همه، گوینده و سرعت را بشنوید.
3. در تب «تست وب‌سرویس»، دکمه‌ی «نمونه‌ی سرعت‌ها» گوینده‌ها و سرعت‌ها را کنار هم می‌سازد تا با گوش انتخاب کنید.
4. «ساخت همه‌ی باقی‌مانده‌ها» را بزنید یا دسته‌ای بسازید (صفحه‌ها، هر بازی، هر مرحله، مدال‌ها، نام صداها…).

اگر واژه‌ای بد خوانده شد، «متن» را بزنید و تلفظ را با اعراب بنویسید. این تلفظ هم در `spoken` و هم در
`tools/content/spoken_fa.json` ذخیره می‌شود (تا ساخت دوباره‌ی محتوا با `build_game.py` آن را پاک نکند) و متنی که
برنامه نشان می‌دهد عوض نمی‌شود.

برای ضبط با صدای خودتان، متن کامل همه‌ی جمله‌ها به ترتیب بازی (با اعراب و نام فایل هر جمله) در
`docs/voice/RECORDING_SCRIPT.md` و `docs/voice/recording_list.csv` است.

**صدای ماشینی و ضبط انسانی کنار هم:** استودیو هرگز فایلی را که در `tts_generated.json` نیست بازنویسی
یا پاک نمی‌کند، پس ضبط گوینده‌ی واقعی همیشه امن است. وقتی ضبط‌ها رسید، این را اجرا کنید:
`tools/voice/import_recordings.sh <پوشه‌ی فایل‌ها>`

## تب «صدای حیوان‌ها و وسایل»

۴۶ صدای فعلی (حیوان‌ها، وسایل خانه، طبیعت، موسیقی، حرفه‌ها، فضا) از نسخه‌ی قبلی آمده‌اند و
**با سنتز ساخته شده‌اند، نه ضبط واقعی**. TTS هم نمی‌تواند صدای گاو بسازد، پس این صداها باید فایل واقعی باشند.

1. صدا را پیدا کنید. منابع رایگان:
   - Freesound با فیلتر مجوز CC0. زیر هر ردیف لینک جست‌وجوی آماده هست.
   - Pixabay Sound Effects
   - BigSoundBank
   - یا ضبط خودتان با گوشی
2. فایل را روی ردیف همان صدا بکشید و رها کنید، یا «انتخاب فایل» را بزنید. فرمت‌های mp3، wav، ogg،
   m4a و حتی ویدئوی mp4 پذیرفته می‌شوند.
3. استودیو با ffmpeg فایل را آماده می‌کند:
   - جلوه‌ها (حیوان‌ها، وسایل، سازها): سکوت اول و آخر را می‌بُرد، طول را حداکثر به «حداکثر طول» می‌رساند
     (پیش‌فرض ۶ ثانیه، با محوشدن آرام در انتها)، مونو و هم‌بلند (−14 LUFS) می‌کند و MP3 می‌سازد
   - صدای محیط (`ambient/*.ogg`، که پشت هر فصل حلقه‌وار پخش می‌شود): چیزی نمی‌بُرد، ۲۴ ثانیه نگه می‌دارد،
     دو ثانیه‌ی آخر را در ابتدا محو می‌کند تا تکرار حلقه درز و پرش نداشته باشد، آرام (−28 LUFS) و OGG می‌سازد.
     فایل دست‌کم ۴ ثانیه باشد؛ ۳۰ ثانیه یا بیشتر بهتر است.
   - **روی همان فایل داخل پروژه** می‌نویسد و فهرست `asset_manifest.json` را هم به‌روز می‌کند
4. «منبع» (لینک) و «مجوز» را بنویسید. در `docs/audio/sfx_sources.json` می‌ماند و برای انتشار در
   بازار لازم است. هر صدایی که آنجا ثبت شود، برچسب «واقعی» می‌گیرد.

صدای قبلی در گیت هست. اگر جایگزینی خوب نبود، برش گردانید:
`git checkout -- assets/audio/animals/cow.mp3`

## تب «خبرها و اعلان‌ها»

همان تب گوش‌یار: خبر (عنوان، متن، عکس، پیوند، صفحه‌ی مقصد، از/تا با تقویم شمسی) همین‌جا نوشته و با کلیدی که
فقط روی همین رایانه است **امضا** می‌شود؛ برنامه هر چیز بی‌امضا را دور می‌ریزد.

1. یک بار «ساخت کلید امضا» ← `assets/notices/notice-key.pub` را کامیت کنید و نسخه‌ی تازه بسازید.
2. تنظیمات FTP (پیش‌فرض `ftp.mp-apdl.ir`، مسیر `/public_html/popo`) ← «تست اتصال» ← «ذخیره».
3. خبر بنویسید ← «افزودن به فهرست» ← «امضا و انتشار».

پیش‌نویس‌ها در `notices.json`، عکس‌ها در `notices/` و فایل امضاشده در `published/` همین پوشه‌اند (هیچ‌کدام در
گیت نیست). راهنمای کامل: [docs/RELEASE.md](../../docs/RELEASE.md).

## آزمایش بدون توکن

`AVASHO_HOST` آدرس سرویس را عوض می‌کند تا بشود با یک سرور ساختگی محلی آزمایش کرد:

```bash
AVASHO_HOST=http://127.0.0.1:9911 npm run server
```
