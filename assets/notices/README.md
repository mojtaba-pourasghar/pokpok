# کلید عمومی خبرها

`notice-key.pub` را استودیو (`tools/voice-studio`، تب «خبرها» ← «ساخت کلید امضا») همین‌جا می‌نویسد.
آن را کامیت کنید. این نیمه‌ی **عمومی** است و فقط می‌تواند امضا را بیازماید، نه امضا کند.
نیمه‌ی خصوصی فقط در `tools/voice-studio/voice-studio.config.json` می‌ماند، که در گیت نیست.

تا این فایل نباشد، برنامه (`lib/data/notices_store.dart`) و کار پس‌زمینه‌ی اندروید (`NoticeWork.kt`)
هیچ خبری را نمی‌پذیرند.
