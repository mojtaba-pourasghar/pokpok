# صدای گوینده (پوپو)

این پوشه عمداً خالی است: **هنوز هیچ صدای ضبط‌شده‌ای وجود ندارد.**

- متن همه‌ی جمله‌ها: `assets/content/voice_lines.json`
- فیلم‌نامه‌ی ضبط برای گوینده: `docs/voice/RECORDING_SCRIPT.md`
- نام هر فایل در فیلد `file` همان جمله آمده، مثلاً `voice/app_splash_welcome.mp3`

فایل‌های ضبط‌شده را با همان نام اینجا بگذارید (یا روی CDN در بسته‌ی `voice-fa`).
تا فایلی نباشد، برنامه متن را در حباب گفت‌وگوی پوپو نشان می‌دهد و بازی متوقف نمی‌شود.
