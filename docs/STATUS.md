## آنچه انجام شده و کار می‌کند

| بخش | انجام‌شده |

| مینی‌بازی | ۲۷ موتور پرانیمیشن با سه پله‌ی راهنما و دشواری بر اساس سن؛ هر بخش ۶ تا ۷ گام |
| جایزه | ستاره (راهنما، اشتباه، زمان؛ برای ۲ تا ۴ سال بی‌زمان؛ والدین می‌توانند زمان را خاموش کنند) و سکه؛ مرتبه‌ی سازنده؛ کارگاه ستاره (۸ کیت)، فروشگاه ابزار (۸ ابزار، ۱۰ دستور ساخت)، اتاق بازی با ترکیب‌ها، سفارش روزانه و جایزه‌ی ورود |

## آنچه هنوز مانده

1. **صدای پوپو** برای جمله‌های تازه: با استودیوی خود پروژه (صاحب پروژه می‌سازد). تا آن زمان حرف‌ها در حباب نوشته می‌شوند.
2. **ساخت و آزمایش روی گوشی واقعی.** در این محیط Android SDK نبود (`dl.google.com` بسته است). روی یک گوشی ضعیف
   اندروید ۱۰ و یک گوشی تازه: `flutter build apk --release` و `flutter run --profile` برای سنجش روانی.
3. **خرید و اعلان‌ها روی دستگاه** ([docs/RELEASE.md](RELEASE.md)) و بررسی حقوقی حریم خصوصی.

## بررسی

```bash
flutter pub get
flutter analyze                 # No issues found
flutter test                    # 126 passed (ابزارهای برگه‌ی بازبینی فقط با TOON_SHEET=1)
flutter build web --release     # ساخته شد و در Chromium (۴۱۲×۹۱۵ و ۱۲۸۰×۸۰۰) بررسی شد
python3 tools/sfx/synth.py && python3 tools/sfx/balance.py && python3 tools/build_manifest.py
python3 cloudflare/scripts/build_packs.py --version v1
cd tools/voice-studio && npm install && npm start      # http://127.0.0.1:5174
```

آنچه با چشم در مرورگر بررسی شد: خانه، نقشه‌ی فصل، مأموریت و چند مینی‌بازی (گرفتن، دوشیدن، ضربه، فوت کردن،
جرثقیل، نقطه‌ها، کارت حافظه) با کارتون‌ها و پس‌زمینه‌های زنده؛ برگه‌ی همه‌ی کارتون‌ها با
`TOON_SHEET=1 flutter test test/tools/` در build/toon_sheets/.
