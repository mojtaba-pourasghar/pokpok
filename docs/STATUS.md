## آنچه هنوز مانده

1. **ساخت و اجرای اندروید و iOS.** در این محیط Android SDK نبود و `dl.google.com` در سیاست شبکه بسته بود؛ macOS هم
   نبود. کد بومی کوتاه است (`MainActivity.kt`، `AppDelegate.swift` فقط برای فضای آزاد) ولی باید روی دستگاه واقعی
   ساخته و آزموده شود: `flutter build apk` و `flutter test integration_test -d <device>`.
2. **صدای گوینده.** هیچ جمله‌ای هنوز صدا ندارد. با `tools/voice-studio` (نیاز به توکن آواشو) یا ضبط استودیو.
3. **تصویرسازی نهایی.** تصویرها طرح برداری اصلی و یکدست‌اند، نه رندر سه‌بعدی مثل تصویر مرجع. مسیر جایگزینی با WebP
   آماده است (`docs/ASSETS.md` §۴).
4. **Cloudflare واقعی.** bucket، Worker و دامنه باید با حساب صاحب پروژه ساخته شوند (`cloudflare/README.md`).
5. **زبان دوم.** متن‌ها فارسی‌اند و در کد نوشته شده‌اند؛ برای زبان دوم باید به ARB/`gen-l10n` منتقل شوند.
6. **خرید.** هیچ فروشگاهی وصل نیست؛ برای فروش، پیاده‌سازی `PurchaseService` برای فروشگاه مقصد لازم است.
7. **بررسی حقوقی حریم خصوصی** و سیاست‌های فروشگاه (بخش کودکان Google Play، Apple Kids Category).
8. **کارایی روی گوشی ضعیف** باید با `flutter run --profile` و DevTools سنجیده شود (اینجا فقط وب بررسی شد).

## بررسی

```bash
flutter pub get
flutter analyze                 # No issues found
flutter test                    # 122 passed, 2 skipped (ابزارهای ساخت تصویر)
flutter build web --release     # ساخته شد و در Chromium (۴۱۲×۹۱۵ و ۱۲۸۰×۸۰۰) بررسی شد
python3 tools/art/build_art.py && python3 tools/sfx/synth.py && python3 tools/build_manifest.py
python3 cloudflare/scripts/build_packs.py --version v1
cd tools/voice-studio && npm install && npm start      # http://127.0.0.1:5174
```

آنچه با چشم در مرورگر بررسی شد: همه‌ی صفحه‌ها در گوشی کوچک و تبلت افقی؛ روشن شدن چراغ با درخشش، کشیدن توپ
روی مبل، حرکت ماشین‌ها روی جاده، رشد دانه با آب‌پاش، کشیدن روی بوم، پازل‌ها، دروازه‌ی والدین.
